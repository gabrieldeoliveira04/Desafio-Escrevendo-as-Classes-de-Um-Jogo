# Heroes Battle System

Projeto desenvolvido como parte do desafio da DIO, com foco na aplicação de conceitos fundamentais de programação orientada a objetos, estruturas de decisão, laços de repetição e desenvolvimento frontend moderno.

Além da implementação da lógica solicitada no desafio original, o projeto foi expandido com a criação de uma interface web completa utilizando Next.js, React, TypeScript e TailwindCSS, proporcionando uma experiência interativa para criação e execução de ataques dos heróis.

A aplicação permite cadastrar heróis com diferentes classes e executar múltiplos ataques automaticamente utilizando estruturas de repetição.

## Objetivo do Projeto

O principal objetivo do projeto foi praticar conceitos fundamentais de programação orientada a objetos, criação de classes, métodos e estruturas condicionais.

Além disso, o projeto também teve como foco evoluir a solução além do desafio original, criando uma interface frontend moderna e responsiva para interação do usuário.

## Funcionalidades

### Cadastro do Herói

* Inserção do nome do herói
* Inserção da idade
* Seleção do tipo do herói
* Definição da quantidade de ataques

### Tipos de Herói

* Guerreiro
* Mago
* Monge
* Ninja

### Sistema de Ataques

* Execução automática de ataques
* Associação automática do tipo de ataque conforme a classe
* Exibição dinâmica das ações do herói
* Utilização de laços de repetição para múltiplos ataques

### Ataques Implementados

* Mago → magia
* Guerreiro → espada
* Monge → artes marciais
* Ninja → shuriken

### Interface da Aplicação

* Interface responsiva
* Formulário interativo
* Feedback visual dos ataques realizados
* Estrutura moderna utilizando TailwindCSS

## Lógica da Aplicação

O sistema realiza:

* Criação de objetos baseados em classes
* Identificação automática do tipo de ataque
* Execução de múltiplos ataques utilizando loops
* Exibição dinâmica das ações na interface
